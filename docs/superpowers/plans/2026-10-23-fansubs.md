# Fansubs from SeaDex and Anime Tosho Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** For AniList titles on the NAS, find the SeaDex-ranked release's subtitle tracks and fonts on Anime Tosho, line each episode up with the owner's disc from its audio, and attach them in the subtitle store (nightly and on demand); let any viewer search Anime Tosho from the player for an episode with nothing attached.

**Architecture:** A new server module `server/src/fansubs/` holds the two service clients (SeaDex, Anime Tosho), pure release and episode choice, the download cache and archive decoding (7z-wasm), the alignment (ffmpeg decodes sampled audio windows from the disc; an energy speech detector; offset and split search against the ASS dialogue), and `FansubService`, which runs titles (button or nightly window) and attaches tracks through an extended `SubtitleStore` (a `source` field, shared fonts, a separate budget). Routes in `server/src/routes/fansubs.ts`. Client: types in `nas-api.ts`, `NasClient` methods, the owner line and episode marks on the season and movie screens, a languages setting on the admin screen, and an Anime Tosho search inside the player's Subtitles menu whose pick is the viewer's own and is kept in their place.

**Tech Stack:** TypeScript (strict), Node 24 server bundled by esbuild, ffmpeg (jellyfin-ffmpeg in the image, system ffmpeg in dev and CI), `7z-wasm` 1.2.0 (WASM build of 7-Zip, for `.xz` and `.7z`), React, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-23-fansubs-design.md`

## Global Constraints

- The NAS server has no native dependencies: `7z-wasm` (WASM) is the only new runtime dependency; ffmpeg stays a spawned binary (`FFMPEG_PATH`).
- Library mounts are read-only; everything fansub-related is written under `<dataDir>/fansubs/` and `<dataDir>/subtitles/`.
- The repo is public: tests, fixtures and recorded answers use made-up titles and groups only ("Starfall Wanderer", "GroupA", "GroupB").
- Polite clients: each service through its own `Pacer(1, 2_500)`; `User-Agent: lookupUserAgent(config.lookupContact)`; every download is cached and never fetched twice; each font pack is fetched once, only when an episode is being attached or picked.
- Base URLs are settings: `SEADEX_URL` (default `https://seadex.moe`), `TOSHO_FEED_URL` (default `https://feed.animetosho.net`), `TOSHO_URL` (default `https://animetosho.net`). A failing service becomes "not found" with a reason, never an error screen.
- English tracks always; other languages only when ticked in the owner's languages setting (default `['eng']`).
- Fansub storage budget `FANSUB_STORE_BYTES`, default 20 GB, separate from the 2 GB of owner uploads; a fetched track over 50 MB (decompressed) is skipped with reason `too-large`.
- Alignment reads sampled stretches (6 windows of 60 s spread over the episode, through the EP map); the whole episode only when windows disagree on the offset by more than 0.3 s.
- The nightly pass runs from the end of the library scan until 08:00 local (`FANSUB_WINDOW_END`, `HH:MM`), pauses while any disc file was read in the last 120 s or a quality level is encoding, and resumes.
- Titles where nothing at all was found are retried after 30 days; done titles are otherwise skipped by the nightly pass.
- Viewer search: any paired person, regardless of `TITLE_LIBRARY`; at most 20 picks per person per hour (`429 too-many`).
- Copy fixed by the spec: line "Fansubs: <group> (SeaDex best) · subtitles from <group> WEB · checked <when>"; buttons "Find fansubs" / "Find fansubs again"; marks "lined up", "lined up · +1.2 s", "split at 11:40 · check", "couldn't line up · set by hand", "no fonts", "not found", "lined up on another disc"; actions "Line up again", "Use original timing"; menu entry "Search Anime Tosho…"; status "Lining up…".
- `src/engine/` must not import from `src/ui/` or `src/player/`. New code under `server/src/fansubs/` is original code (no NOTICE entry) except where noted.

## Review Focus

1. **A batch whose file names carry absolute numbers or no number at all** (`- 14` for season 2 episode 2, `[GroupA] Starfall Wanderer [BD 1080p].mkv` for a movie, `NCOP1`): expect the right episode, the movie's main file, and creditless/extra files ignored. Pinned in Task 4.
2. **A track with no dialogue the speech detector can use** (signs-only, songs-only, or almost empty): expect "couldn't line up · set by hand" (the track attached unshifted), never a confident wrong offset. Pinned in Task 7.
3. **Anime Tosho or SeaDex down, slow, or answering HTML instead of JSON**: expect the title's run to end with `not-found` reasons (`service-unavailable`) and a retry next night, never a crashed pass or a half-attached title. Pinned in Task 9.
4. **The owner deletes a fansub track, then the nightly pass runs again**: expect it to stay deleted; and an owner's offset on a track survives a rerun that brings the same track back. Pinned in Task 9.
5. **A viewer's pick on resume after the NAS cache dropped the files, or after the person hit their hourly limit**: expect a re-fetch (counted) or a notice "Couldn't load the subtitles from Anime Tosho." with the subtitles left as they were. Pinned in Task 13.

### Task 6: Speech, dialogue and retiming

**Files:**
- Create: `server/src/fansubs/speech.ts`, `server/src/fansubs/dialogue.ts`, `server/src/fansubs/retime.ts`
- Test: `server/src/fansubs/speech.test.ts`, `server/src/fansubs/dialogue.test.ts`, `server/src/fansubs/retime.test.ts`

**Interfaces:**
- Consumes: `AudioWindow` (Task 5), `parseAss` (`src/engine/ass/parse.ts`).
- Produces:
  - `speechMask(window: AudioWindow): Uint8Array` — one byte per 10 ms frame from `window.startMs`: 1 where the frame is speech. Energy with an adaptive floor: a frame is speech when its RMS is 12 dB over the window's 20th-percentile frame RMS, smoothed by closing gaps under 200 ms and dropping runs under 150 ms.
  - `dialogueIntervals(ass: string): { fromMs: number; toMs: number }[]` — events that are dialogue: not commented, style name not matching `/sign|song|op|ed|kara|title|insert|note/i`, text without `\pos`, `\move`, `\k`/`\kf`/`\ko` tags, duration 300 ms–10 s; merged when overlapping.

Times are clamped at 0 and written as `H:MM:SS.cc` (centiseconds, rounded).
